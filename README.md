# 展锐UDX710 LTE频段解析器

## 简介
这是一个用于解析展锐(UNISOC) UDX710芯片AT+SPLBAND=0命令返回值的Python工具，可以将原始的数字编码转换为可读的LTE频段信息。

## 功能特性
- 解析AT+SPLBAND=0命令返回的频段编码
- 显示支持的LTE频段详细信息
- 提供FDD/TDD频段分类
- 显示频段的区域覆盖情况
- 支持全球主要LTE频段标准

## 使用方法

### 运行解析器
```bash
python3 final_parser.py
```

### 输入数据格式
AT+SPLBAND=0命令返回格式：`0,482,0,149,0`

## 技术说明

### 编码原理
展锐UDX710使用5个32位整数来编码支持的LTE频段：
- 格式：`[组1, 组2, 组3, 组4, 组5]`
- 每个组的每个位对应特定的LTE频段
- 位值为1表示支持该频段

### 位映射方式
- **第2组 (482 = 0x1E2)**：主要映射Band 2, 6, 7, 8, 9
- **第4组 (149 = 0x95)**：主要映射Band 1, 3, 5

### FDD vs TDD
- **FDD (频分双工)**：上行和下行使用不同频率
- **TDD (时分双工)**：上行和下行使用相同频率但不同时间

## 兼容性
- 支持Python 3.x
- 基于3GPP TS 36.101 LTE频段标准
- 适用于展锐UDX710及类似芯片

## 注意事项
1. 解析结果显示芯片支持的频段，实际可用频段取决于：
   - 当地运营商网络配置
   - 设备天线设计
   - 监管政策限制

2. 不同区域的运营商使用不同的LTE频段组合

3. 该解析器基于对展锐芯片编码方式的逆向分析，可能需要根据不同芯片版本进行调整
